⚡ Laravel Request Lifecycle Architecture

Perjalanan sebuah permintaan (request) dari pengguna hingga menjadi respons yang diterima kembali oleh browser.

1
👤💻

User Request

Pengguna mengirimkan permintaan melalui browser (HTTP/HTTPS), misalnya membuka halaman web atau mengirim data formulir.

public/index.php
2
🌐⚙️

Request Masuk ke Web Server

Permintaan diterima oleh web server (Apache/Nginx) yang bertugas meneruskan seluruh proses masuk ke dalam sistem aplikasi.

Apache / Nginx
3
⚙️🚀

Proses di Aplikasi (Route & Controller)

Aplikasi PHP memproses permintaan, mencocokkan jalur (routing), lalu menjalankan logika bisnis di dalam Controller.

routes/web.php & Controller
4
🗄️📊

Akses ke Database

Jika diperlukan, aplikasi mengirimkan query ke database untuk mengambil, memodifikasi, atau menyimpan data melalui Model.

Eloquent ORM / SQL
5
📑🔄

Respons Diproses (Blade Engine)

Data dari database diolah dan dilempar ke template Blade untuk dirender menjadi format HTML yang bersih dan dinamis.

resources/views/*.blade.php
6
📦🌐

Respons Dikirim ke Client

Web server mengirimkan kembali respons matang ke browser pengguna melalui protokol standar HTTP/HTTPS.

HTTP Response
7
🖥️✨

Tampilan di Browser

Browser menerima paket respons tersebut dan menampilkannya secara visual kepada pengguna dalam bentuk halaman web yang interaktif.

Render HTML / CSS / JS

Catatan Arsitektur: Siklus permintaan Laravel memastikan pemisahan tugas yang jelas (*Separation of Concerns*) antara penanganan rute, logika pengontrol, interaksi basis data, hingga penyajian antarmuka pengguna.
